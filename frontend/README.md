# 🚀 Product Management System

A MERN Stack hackathon project for managing products with a clean and modern UI inspired by Odoo.

This application allows users to:
- Add products
- View all products
- Manage product information
- Store product data using MongoDB

---

# 📌 Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Fetch API
- Vite

## Backend
- Node.js
- Express.js

## Database
- MongoDB
